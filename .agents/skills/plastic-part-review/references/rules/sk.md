# R-SK 缩水与变形风险类规则（12 条）

本类是"结果类"规则：筋、柱、壁厚的最终代价都体现在缩水（缩痕/缩孔）与变形（翘曲/扭曲）。审查时用截面比快速判定料聚，再按根因顺序定位变形。
联动：全部类别（R-SK-01 是料聚总判定，其他类命中后交叉引用本类定级）。

## R-SK-01 料聚判定基准（总判定规则）
- **适用**：所有局部截面变化处（筋、柱、交汇、台阶、厚区）
- **规则**：局部截面厚度 > 1.25×t 判定料聚风险（缩痕/缩孔）；**A 面背面阈值收紧至 1.15×t**（经验区间——外观等级越高阈值越紧）
- **来源**：材料商设计指南 + 行业经验区间
- **意见映射**：A 面背面 > 1.15×t → B；非外观 > 1.25×t → B；> 1.5×t → A/B（视位置与外观等级）

## R-SK-02 厚壁中心空洞
- **适用**：厚截面实心区（> 4mm）
- **规则**：厚壁中心冷却最慢 → 内部真空缩孔/空洞（外观件表面缩坑、剖切可见空洞）；必须掏胶或改中空结构（联动 R-BT-04）
- **来源**：注塑成型原理（A 类，聚合物加工教科书）
- **意见映射**：> 4mm 无减胶 → B；外观件 > 5mm → A

## R-SK-03 大平板翘曲
- **适用**：大面积平面/浅壳体
- **规则**：大面积等厚薄板（无筋/无拱曲）翘曲风险高——冷却不均 + 残余应力释放；对策：加筋、双向拱曲（每 100mm 拱 0.5–1.5mm 经验）、非对称补偿（联动 R-RB-08）
- **来源**：行业经验区间
- **意见映射**：大平板无加强 → B；带筋但筋距 > 5×筋高 → B/C

## R-SK-04 结构对称性
- **适用**：壳体、盖板类零件
- **规则**：零件两侧（模具上下模侧）结构不对称（如一面密筋一面光面）→ 两侧收缩差 → 翘曲；力求对称，必要时加"假筋"平衡收缩
- **来源**：注塑成型原理（A 类，聚合物加工教科书）
- **意见映射**：严重不对称 → B；轻微不对称 → C（提示试模监控）

## R-SK-05 材料收缩率分组
- **适用**：材料选定后的尺寸/公差/变形整体评估
- **规则**：非晶材料（ABS/PC/PMMA/PS）收缩 0.4–0.7%；半结晶（PP 1.0–2.5%、PA 0.8–2.0%、POM 1.5–2.5%）；GF 增强后整体下降但**各向异性**（流动向/垂直向差可达数倍）；大收缩材料从严审公差与变形
- **来源**：材料数据表通用区间
- **意见映射**：半结晶材料 + 精密公差要求 → B；各向异性未考虑 → C

## R-SK-06 浇口位置与痕迹
- **适用**：图纸标注浇口/进浇方案的评审；未标注时提示
- **规则**：A 面禁止直接浇口（点浇口痕/潜伏口留痕评估）；浇口区残余应力高、取向强——附近尺寸与变形受影响；大件多浇口需平衡
- **来源**：塑料模具设计手册通用做法（A 类，见《塑料模设计手册》）
- **意见映射**：A 面浇口 → B；浇口未知 → D（存疑：要求模具厂提供进浇方案或做模流）

## R-SK-07 熔接线质量确认
- **适用**：所有熔接线预估位置（孔后、多浇口汇合处、绕障汇流）
- **规则**：熔接线强度与外观依赖温度/压力/排气——结构评审只能定位**风险位置**，最终质量需模流分析或试模确认；改善手段：移浇口、导流凸台、冷料井、排气
- **来源**：注塑成型通用
- **意见映射**：A 面/受力区熔接线 → D（存疑：建议模流分析）+ 结构改善建议 C

## R-SK-08 顶针痕控制
- **适用**：顶出方案涉及外观面的零件
- **规则**：顶针位留痕（凹坑/拖白）——结构上把顶针位预留到 B 面、筋端、柱端（联动 R-RB-12）；A 面确需顶针时用扁顶针/顶块并注明外观要求
- **来源**：塑料模具设计手册通用做法（A 类，见《塑料模设计手册》）
- **意见映射**：未预留且 A 面大面积光面 → C（模具反馈项）

## R-SK-09 应力发白
- **适用**：卡扣折弯区、强制装配区、过盈配合区
- **规则**：局部高应变在脆性材料（纯 PC、PMMA、PS）上表现发白/微裂；对策：韧性牌号（PC/ABS）、降应变（联动 R-SN-04）、过渡圆角
- **来源**：材料失效经验
- **意见映射**：脆性材料 + 高应变区 → B

## R-SK-10 后收缩与尺寸稳定
- **适用**：精密配合、装配关系严格的零件
- **规则**：注塑件出模后继续后收缩（24–48h 才基本稳定，尺寸检测时点应在图纸注明）；高要求件退火处理稳定尺寸；长期高温工况选低后收缩/增强材料
- **来源**：材料商数据 + 行业经验
- **意见映射**：精密配合无检测时点/后处理说明 → C

## R-SK-11 嵌件周围开裂
- **适用**：金属嵌件（螺母、销套）包覆区
- **规则**：金属/塑料热膨胀系数差 + 包覆应力 → 周期性开裂（低温、湿热老化加速）；对策：包胶厚度（联动 R-BT-09）、嵌件预热、嵌件自身滚花/圆角无刃口、避免嵌件区受装配应力
- **来源**：行业经验
- **意见映射**：包胶不足或嵌件有尖刃 → B

## R-SK-12 变形根因排查顺序（方法论）
- **适用**：评审中发现翘曲/变形疑点时的定位
- **规则**：按顺序排查：① 结构对称性（R-SK-04）→ ② 壁厚均匀性（R-BT-02）→ ③ 局部料聚（R-SK-01）→ ④ 浇口位置（R-SK-06）→ ⑤ 冷却（模具侧）；结构能解决的优先于靠工艺参数硬调
- **来源**：行业评审方法论
- **意见映射**：本条为方法规则不单独发意见，用于支撑变形类意见的依据链
