# R-BS 螺丝柱类规则（12 条）

螺丝柱是爆柱、滑牙、缩水三大高频问题的源头。审查顺序：**定螺丝规格 → 查底孔 → 查柱外径 → 算柱壁厚 → 查减胶与支撑**。
联动：R-SK-01（柱区料聚）、R-DM-06（孔芯斜度）、R-RB-11（角撑）。

## R-BS-01 柱外径经验值
- **适用**：自攻螺丝柱
- **规则**：柱外径 OD ≈ (1.8–2.2)× 螺纹公称直径：

| 螺丝 | M1.6 | M2.0 | M2.3 | M2.6 | M3.0 |
|---|---|---|---|---|---|
| OD（mm） | 3.0–3.5 | 3.5–4.0 | 4.0–4.5 | 4.4–5.0 | 5.2–6.0 |

- **来源**：行业经验区间（各厂企标有差异，以锁附扭力试验为准）
- **意见映射**：OD < 1.6×d → B（柱体胀裂）；OD > 2.4×d → C（料聚缩水、成本）

## R-BS-02 自攻底孔直径
- **适用**：自攻螺丝（K30/K40 型）底孔
- **规则**：按材料硬软分组取值（**经验区间**，最终按螺丝厂商底孔推荐表 + 扭力验证）：

| 螺丝 | 硬材料（PC/ABS/PS/POM） | 软材料（PA/PP/PE） |
|---|---|---|
| M1.6 | Ø1.30–1.40 | Ø1.25–1.35 |
| M2.0 | Ø1.65–1.75 | Ø1.55–1.65 |
| M2.6 | Ø2.15–2.25 | Ø2.05–2.15 |
| M3.0 | Ø2.55–2.65 | Ø2.45–2.55 |

- **来源**：行业经验区间 + 自攻螺丝厂商（如自攻螺钉规格手册）推荐
- **意见映射**：底孔偏小（低于下限 0.1mm+）→ B（扭力过大爆柱）；偏大（高于上限 0.1mm+）→ B（攻入牙不足滑牙）

## R-BS-03 有效旋合长度
- **适用**：自攻螺丝柱
- **规则**：有效旋合长度 ≥ 2×d（或 ≥ 6 牙）；常用 2–2.5×d
- **来源**：行业通用经验
- **意见映射**：< 1.5×d → B（抗拔/扭矩不足）；1.5–2×d → C（要求扭力验证）

## R-BS-04 柱壁厚
- **适用**：所有螺丝柱
- **规则**：柱壁厚 =（OD − 底孔）/2 ≤ 0.6×t；孤立柱（远离侧壁）≤ 0.75×t 且必须配合减胶；柱壁过厚是爆柱与缩水的双重源头
- **来源**：材料商设计指南通用
- **意见映射**：0.6–0.75×t 无减胶 → B；> 0.75×t → B；A 面背面 > 0.6×t → B

## R-BS-05 柱减胶结构
- **适用**：粗柱、长柱、实心区柱
- **规则**：长柱中心掏胶（十字减胶/环槽），保持柱壁厚均匀且接近 0.5×t；柱底与主壁连接处减胶台阶，防止柱根料聚（柱区截面 ≤ 1.25×t，联动 R-SK-01）
- **来源**：行业通用做法
- **意见映射**：柱区截面 > 1.25×t 无减胶 → B；> 1.5×t → A/B

## R-BS-06 孔口与柱底细节
- **适用**：所有螺丝柱
- **规则**：底孔口导引倒角 C0.3–0.5（防螺丝偏斜啃料）；盲孔柱底最小厚度 ≥ 0.5×t（防顶白/背面缩痕）
- **来源**：行业通用经验
- **意见映射**：无倒角 → C；柱底厚 < 0.4×t → B

## R-BS-07 柱与侧壁的关系
- **适用**：贴侧壁布置的螺丝柱
- **规则**：柱紧贴侧壁会造成外壁局部加厚缩水——柱外缘与侧壁间留 ≥ 0.5–1.0mm 间隙，或与侧壁连成整体后从侧壁内侧掏空（**经验区间**）
- **来源**：行业通用做法
- **意见映射**：柱贴壁未掏空 → B（外壁缩痕带）

## R-BS-08 细长孔型芯
- **适用**：底孔深径比大的柱
- **规则**：底孔 H/d > 3 时分段变径或改通孔（型芯两端支撑）；过细长型芯在注射压力下让位 → 偏孔、壁厚不均
- **来源**：模具设计通用
- **意见映射**：H/d > 4 盲孔 → B（偏孔风险）

## R-BS-09 超声/热压嵌件柱
- **适用**：五金嵌件（超声螺母、热压螺母）
- **规则**：嵌件底孔 = 嵌件外径 − 0.05 ~ −0.15 过盈量（**按嵌件厂商规格表**，如 Ø5.6 外径嵌件底孔 Ø5.45–5.55）；嵌件埋入后顶面低于塑料面 ≥ 0.3mm；嵌件周围包胶壁厚联动 R-BT-09
- **来源**：嵌件厂商（SPIROL 类）推荐表 + 行业经验
- **意见映射**：过盈量超范围 → B（嵌件松动或胀裂）；无规格依据 → D（存疑，要求提供嵌件型号）

## R-BS-10 细长柱支撑与防跌伤
- **适用**：柱高/柱径 > 3 的螺丝柱
- **规则**：加角撑（联动 R-RB-11）防充填偏折与顶出变形；产品跌落时柱顶受冲击的位置，柱高预留压缩量或降柱/加缓冲筋（**经验区间**，按跌落高度与材料）
- **来源**：行业经验区间
- **意见映射**：细长无撑 → B；跌落冲击位长柱 → B

## R-BS-11 材料与锁附扭矩
- **适用**：螺丝柱材料选择与装配工艺
- **规则**：纯 PC 柱脆（易裂），优先 PC/ABS；装配扭矩按材料与规格给定范围并做扭力测试（M2 自攻进 PC/ABS 经验 2–4 kgf·cm 级，**经验区间**，以实测为准）
- **来源**：行业经验区间
- **意见映射**：纯 PC 柱 + 无降扭矩措施 → C；图纸无扭矩要求 → C

## R-BS-12 柱位与过孔公差
- **适用**：两件螺丝连接的柱/孔配合
- **规则**：柱位置度（两件叠加累计）建议 Ø0.2–0.5（MMC 基准）；被连接件过孔 = 螺丝中径 + 0.4–0.6 间隙（M2 过孔 Ø2.4–2.6）（**经验区间**）
- **来源**：行业经验区间
- **意见映射**：位置度 < Ø0.2 → C（模具与装配成本）；过孔无间隙 → B（螺丝干涉）
