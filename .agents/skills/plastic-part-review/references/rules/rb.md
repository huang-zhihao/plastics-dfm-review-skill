# R-RB 加强筋类规则（12 条）

筋是最常用的刚度手段，但每条筋都是一个潜在缩水源。审查要点：**先算筋厚/壁厚比，再看高度、圆角、间距、交汇**。
联动：R-SK-01（料聚判定）、R-DM-05（筋斜度）、R-BT-08（以筋代厚）。

## R-RB-01 筋厚比（防缩水核心规则）
- **适用**：所有加强筋
- **规则**：筋根部厚度 ≤ 0.6×t；位于 A 面背面（筋对面是外观面）的筋 ≤ 0.5×t
- **来源**：材料商注塑设计指南通用推荐（Bayer/Covestro、BASF 一致）
- **意见映射**：0.6–0.7×t 非外观区 → C；> 0.6×t 且 A 面背面 → B（可见缩痕）；> 0.8×t → A（缩痕/缩孔难以遮蔽）

## R-RB-02 筋高上限
- **适用**：所有加强筋
- **规则**：筋高 ≤ 3×t（名义壁厚）；更高时须加大根部圆角与斜度并做顶出校核；刚度不足时加密筋距而非加高单筋
- **来源**：行业通用经验
- **意见映射**：> 3×t 无加强措施 → B（翘曲、顶出变形）

## R-RB-03 筋根部圆角
- **适用**：所有加强筋根部
- **规则**：根部圆角 R = (0.25–0.4)×t（常用 R0.3–1.0）；圆角 > 0.5×t 反而加重背面缩水——A 面背面的筋取小值
- **来源**：材料商设计指南通用（应力集中与缩水的权衡）
- **意见映射**：无圆角（尖根）→ B（应力集中、脆裂）；受力筋无圆角 → A；圆角 > 0.5t 在 A 面背面 → B

## R-RB-04 筋顶部厚度
- **适用**：有斜度的筋（即所有筋）
- **规则**：顶部厚度 = 根厚 − 2×筋高×tan(斜度)，顶厚 ≥ 0.5×根厚且 ≥ 0.5mm；过尖顶端部困气烧焦
- **来源**：行业通用经验
- **意见映射**：顶厚 < 0.5mm → B（困气、填充不良）；顶厚未核算 → C

## R-RB-05 筋间距
- **适用**：多筋布置（格栅、网格筋）
- **规则**：相邻筋净间距 ≥ 2×t（推荐 ≥ 3×t），保证填充、冷却均匀与顶出
- **来源**：行业通用经验
- **意见映射**：< 2×t → C（收缩不均）；< 1×t → B（填充/排气问题）

## R-RB-06 筋走向顺流动方向
- **适用**：筋布置方案
- **规则**：主筋走向尽量顺熔体主流方向，减少压力损失与熔接线；垂直流向的筋在下游产生熔接线（联动 R-SK-07）
- **来源**：材料商设计指南通用
- **意见映射**：垂直流向筋位于 A 面/受力区下游 → C + 转熔接线评估（R-SK-07）

## R-RB-07 交汇处减胶
- **适用**：筋与筋、筋与侧壁、筋与柱的交汇
- **规则**：交汇处局部截面 ≤ 1.25×t（联动 R-SK-01），超限时在交汇区掏胶（减胶孔/凹坑/十字槽）
- **来源**：行业通用做法
- **意见映射**：交汇截面 > 1.25×t 无减胶 → B；A 面背面交汇料聚 → B 起步

## R-RB-08 大平面布筋方案
- **适用**：大面积壳体/面板刚度
- **规则**：用网格筋（方格/菱形）替代加厚；筋距经验值 1.5–3× 筋高（按挠度要求校核）；薄板（t ≤ 1.5）加密
- **来源**：行业经验区间
- **意见映射**：大平面无筋或疏筋（筋距 > 5×筋高）→ C；叠加翘曲风险因素（R-SK-03）→ B

## R-RB-09 A 面缩痕遮蔽手段
- **适用**：A 面背面必须布置筋/柱时
- **规则**：优先级：① 降厚比至 0.5×t 以下 → ② A 面纹理遮蔽（纹深与缩痕等级匹配）→ ③ A 面曲面/台阶造型分散视线 → ④ 局部减薄 A 面区壁厚（联动 R-BT-06）
- **来源**：行业通用做法
- **意见映射**：无可遮蔽措施的 A 面背面筋 → B；给了措施 → C（确认措施可行性）

## R-RB-10 深筋困气
- **适用**：筋高 > 5×筋厚的深筋、筋端接近分型面
- **规则**：深筋端部是末填区，易困气烧焦/短射——加大斜度、端部预留排气（顶针位/镶件缝，联动 R-RB-12）
- **来源**：行业经验
- **意见映射**：深筋密布且无排气预留 → B（试模烧焦风险）

## R-RB-11 角撑板（Gusset）
- **适用**：立柱、立墙的加强
- **规则**：三角角撑厚度 ≤ 0.6×t；高度约为支撑高度的 1/2–2/3；用梯形（去尖角）优于直角三角（**经验区间**）
- **来源**：行业经验区间
- **意见映射**：无角撑的细长柱/悬墙 → C 起步（联动 R-BS-10）

## R-RB-12 筋端顶出预留
- **适用**：高筋、密筋区域
- **规则**：结构上在高筋端部/交汇处预留顶针位（在 B 面/非外观区），避免顶针落在 A 面（联动 R-SK-08）
- **来源**：模具设计通用约定
- **意见映射**：未预留 → C（模具反馈项）
