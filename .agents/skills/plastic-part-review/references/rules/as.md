# R-AS 装配公差类规则（8 条）

多零件装配的评审核心：**间隙给多少、公差怎么分配、定位靠什么**。先确认装配对象与方式，再查本类。
联动：R-BS-12（柱位与过孔）、R-SK-05（材料收缩）、R-SK-10（后收缩）。

## R-AS-01 配合间隙基础
- **适用**：两件配合面（非活动）
- **规则**：固定配合（胶水/超声/扣合）间隙 0.1–0.2mm；活动配合（需滑动/旋转）0.2–0.4mm；大尺寸件或收缩大的材料（PP/PA）取上限（B 类经验值）
- **来源**：行业通用经验值（B 类）
- **意见映射**：活动件间隙 <0.2 → B（装配干涉/卡滞）；固定配合间隙 >0.4 → C（晃动）

## R-AS-02 公差累积
- **适用**：两件及以上装配的关键尺寸
- **规则**：装配关键尺寸按尺寸链核算累积（两件公差 ±a/±b 叠加，最差情况为代数和）；±0.1mm 级零件叠加后可轻易达到 ±0.3——关键配合尺寸在图纸标公差并核算链长
- **来源**：尺寸链公差分析通用方法（A 类）
- **意见映射**：关键配合无公差标注 → C；标注后累积超配合间隙 → B（干涉）

## R-AS-03 定位优先于紧固
- **适用**：所有多件装配
- **规则**：先定位后紧固——定位柱/孔（圆锥销、棱形销）优先承担位置，螺丝/卡扣只负责锁紧；≥2 个定位点避免旋转自由度未约束；>2 个定位点防过定位（长方向用腰形孔/棱形销释放一个方向）
- **来源**：机械装配定位原理（A 类）
- **意见映射**：无独立定位、靠螺丝硬定 → B（装配误差大）；定位过定位 → B

## R-AS-04 止口与外观缝隙
- **适用**：上下盖类闭合壳体
- **规则**：止口（rim/lip）配合间隙 0.1–0.2mm 定位；外观缝隙（两件接合处）目标 0.3–0.5mm 均匀——缝隙均匀靠止口定位而非零件公差硬扛；止口侧向间隙 + 尺寸公差 ≤ 外观缝隙目标
- **来源**：消费电子结构设计通用（B 类经验值）
- **意见映射**：无止口定位 → B（缝隙不匀）；缝隙目标 <0.3 且无公差分析 → B

## R-AS-05 螺丝过孔间隙
- **适用**：螺丝穿过件（被连接件）
- **规则**：过孔 = 螺丝中径 + 0.4–0.6mm 间隙（M2 过孔 Ø2.4–2.6；M2.6 过孔 Ø3.0–3.2）（B 类经验值）；过孔小 → 螺丝干涉偏斜；大 → 定位失效（联动 R-BS-12）
- **来源**：行业通用经验值（B 类）
- **意见映射**：过孔无间隙 → B

## R-AS-06 热膨胀差异
- **适用**：不同材料装配（金属+塑料、不同塑料）
- **规则**：金属/塑料线胀系数差约 5–10 倍——跨温域装配件（户外/车载）长尺寸方向需释放变形（腰形孔/浮动结构）；塑料互配（PP/PC 差 2–3 倍）长件同理
- **来源**：材料物理性质通用（A 类）
- **意见映射**：跨温域长尺寸无释放 → B；未评估 → C

## R-AS-07 公差基准与 MMC
- **适用**：图纸公差标注
- **规则**：标注基准（A/B/C）与位置度，配合孔用 MMC（最大实体）放宽公差成本；未注公差按 GB/T 14486 相应等级；基准缺失 → 无法稳定检验
- **来源**：GD&T 通用 + GB/T 14486（A 类）
- **意见映射**：无基准关键位置度 → C；要求超工艺能力（联动 R-HL-12）→ B

## R-AS-08 装配导向与防呆
- **适用**：装配方向容易装反/难对位的零件
- **规则**：装配入口做导向斜度/倒角（≥0.5×0.5 C 角或 15°–30° 导入角）；不对称结构防呆（非对称定位、颜色/标识）；图面标注装配方向
- **来源**：装配设计通用（B 类经验值）
- **意见映射**：对称件无防呆 → B（现场装反率）；无导向入口 → C
