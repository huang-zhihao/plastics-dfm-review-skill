# R-HL 孔与圆角类规则（12 条）

孔看三件事：位置关系（间距/边距）、深度（型芯刚性）、方向（开模 vs 侧向）。圆角看一件事：内角绝不允许尖角。
联动：R-BS-08（柱底孔）、R-DM-06（孔芯斜度）、R-HL-06 ↔ R-SN-05（卡扣根部）。

## R-HL-01 孔间距与孔边距
- **适用**：所有孔（功能孔、散热孔、工艺孔）
- **规则**：孔与孔、孔与零件边缘距离 ≥ 1× 孔径（最小），推荐 ≥ 2× 孔径，且不小于 2×t；过近导致熔接线聚集、边缘翘曲
- **来源**：材料商设计指南通用
- **意见映射**：< 0.5×d → B（强度/翘曲）；0.5–1×d → C

## R-HL-02 盲孔深径比
- **适用**：盲孔（非通孔）
- **规则**：d ≥ 1.5mm 时 H ≤ 3×d；细孔（d < 1.5mm）H ≤ 2×d；超深型芯让位 → 偏孔、飞边
- **来源**：塑料模具设计手册通用做法（A 类，见《塑料模设计手册》）
- **意见映射**：H > 4×d → B（偏孔风险）；3–4×d → C（要求模具确认型芯）

## R-HL-03 侧向孔的模具代价
- **适用**：孔轴线垂直于开模方向
- **规则**：侧向孔需要滑块（行位）或斜顶——成本、周期上升，分型线痕/挤压痕出现在外观面附近时需评估；结构设计优先改为开模方向孔（贯通/台阶/两半对孔）
- **来源**：塑料模具设计手册通用做法（A 类，见《塑料模设计手册》）
- **意见映射**：可改开模方向而未改 → C（成本）；A 面附近滑块分型线 → B（外观）

## R-HL-04 孔后熔接线
- **适用**：熔体流动路径上的孔（尤其孔阵列、大孔）
- **规则**：熔体绕孔后在下游汇合形成熔接线；位于 A 面、透明区或受力区的熔接线需评估——结构手段：孔后加导流凸台、移浇口、改孔位（联动 R-SK-07）
- **来源**：材料商设计指南通用
- **意见映射**：A 面/受力区孔下游熔接线 → D（存疑，建议模流分析确认）+ 结构改善建议 C

## R-HL-05 通孔优于盲孔
- **适用**：长孔设计选择
- **规则**：通孔（型芯两端支撑）刚性远高于盲孔（悬臂型芯），长孔优先通孔；同轴阶梯孔直径差要渐变，避免台阶料聚
- **来源**：塑料模具设计手册通用做法（A 类，见《塑料模设计手册》）
- **意见映射**：长盲孔可改通孔未改 → C

## R-HL-06 内圆角下限（尖角禁令）
- **适用**：所有内凹角（壁交角、孔口角、槽底角、卡扣根部）
- **规则**：内角 R ≥ 0.25×t（常用 ≥ 0.3×t，绝对最小 R0.3–0.5mm）；尖内角 = 缺口效应，是冲击开裂与应力开裂的首要源头
- **来源**：材料商设计指南通用
- **意见映射**：受力区/冲击区尖角 → A；一般区域尖角 → B；R < 0.25×t → C

## R-HL-07 内外圆角协调
- **适用**：零件外角（如盒体四个角）
- **规则**：外圆角 ≈ 内圆角 + 壁厚（内 R0.3t ↔ 外 R1.3t），角区保持等壁厚；只圆内角不圆外角 → 角区外壁料聚缩水
- **来源**：材料商设计指南通用
- **意见映射**：内外不协调 → B（角区缩痕/翘曲）

## R-HL-08 直角区例外清单
- **适用**：允许直角的少数位置
- **规则**：仅分型面、配合止口面、滑块成型面允许直角/尖角；其余内角一律圆角（模具圆角还比尖角电极加工成本低、寿命高）
- **来源**：塑料模具工艺手册通用做法（A 类）
- **意见映射**：非例外区直角 → C（联动 R-HL-06 判严重度）

## R-HL-09 孔口倒角
- **适用**：装配孔、自攻底孔、销钉孔
- **规则**：孔口倒角 C0.2–0.5（导引、防崩边）；自攻底孔口倒角联动 R-BS-06
- **来源**：行业通用经验
- **意见映射**：无倒角 → C

## R-HL-10 阵列孔布置
- **适用**：散热孔、喇叭孔、装饰孔阵列
- **规则**：阵列孔距均一、布置对称（平衡收缩防翘曲）；大面积孔区避免局部密集（收缩不均翘曲），孔区与实体区交接处加过渡
- **来源**：行业通用经验
- **意见映射**：不对称大阵列 → C；密排无过渡 → C/B

## R-HL-11 沉孔与沉头
- **适用**：沉头螺钉孔
- **规则**：沉孔直径/深度按紧固件标准（如十字槽沉头自攻钉，M2 沉头孔 Ø4.0 左右，按所选钉规格查表）；沉孔深度留 0.1–0.3mm 余量防钉头干涉凸出
- **来源**：紧固件标准 + 行业经验
- **意见映射**：沉孔尺寸无标准依据 → C；钉头会凸出 A 面 → B

## R-HL-12 孔径公差能力
- **适用**：孔径有配合公差要求（销孔、定位孔、轴孔）
- **规则**：注塑孔径能力 ±0.05–0.10mm（≤18mm，联动 GB/T 14486）；关键配合孔：标注公差 + 模具留修正量（初切偏小或做镶件可换修），PP/PA 大收缩材料的精密孔从严评审（联动 R-SK-05）
- **来源**：行业经验 + GB/T 14486
- **意见映射**：公差要求 < ±0.03 → B（工艺能力不足，需镶件/后加工方案）
