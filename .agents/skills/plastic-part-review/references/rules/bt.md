# R-BT 壁厚类规则（12 条）

主壁厚是注塑件一切特征尺寸的基准（筋、柱、卡扣的限值都以 t 为倍数表达）。审查顺序：先确认名义壁厚 t → 再查本类规则 → 最后才审其他类。
联动：R-SK-01（料聚判定）、R-RB-01（筋厚比）、R-BS-04（柱壁厚）。

## R-BT-01 常用材料推荐壁厚区间
- **适用**：确定/校核零件名义壁厚 t
- **规则**：常用材料壁厚（mm）：

| 材料 | 常用区间 | 极限最小 | 最大 |
|---|---|---|---|
| ABS | 1.2 – 3.0 | 0.8 | 4.0 |
| PC | 1.5 – 4.0 | 1.0 | 4.5 |
| PC/ABS | 1.2 – 3.5 | 0.8 | 4.0 |
| PP | 0.8 – 3.0 | 0.5 | 4.0 |
| PA6 / PA66（未增强） | 0.8 – 2.5 | 0.5 | 3.0 |
| PA+GF30 | 1.5 – 3.0 | 1.0 | 4.0 |
| POM | 1.0 – 3.0 | 0.4 | 3.5 |
| PS / HIPS | 1.0 – 3.0 | 0.6 | 3.8 |
| PMMA | 1.5 – 5.0 | 1.0 | 6.0 |
| TPU | 1.0 – 3.0 | 0.6 | 5.0 |

- **来源**：材料商注塑设计指南通用推荐区间（Bayer/Covestro、BASF、SABIC 指南一致区间，具体牌号略有差异）
- **意见映射**：超出最大值 → B（缩水/周期）；低于极限最小值 → B（短射/强度）；在极限内但出常用区间 → C（要求设计说明理由）

## R-BT-02 壁厚均匀与厚薄过渡
- **适用**：同一零件存在不同壁厚区域
- **规则**：尽量等壁厚；不可避免时相邻厚薄比 ≤ 2:1，且必须渐变过渡——过渡区长度 ≥ 3× 厚度差，或用 15°–45° 锥面/圆弧过渡，禁止台阶突变
- **来源**：材料商设计指南通用
- **意见映射**：台阶突变过渡 → B；厚薄比 >2:1 且无过渡 → B（外观面 A）；厚薄比 >3:1 → A（填充/缩水不可控）

## R-BT-03 流程比（L/t）校核
- **适用**：薄壁、长流程、大件；评估能否充满
- **规则**：经验流程比上限——ABS/PC 约 100–150:1，PA 约 150–250:1，PP 约 200–300:1（随牌号、浇口形式变化，标注为**经验区间**）。壁厚减薄时按最远流程核算 L/t
- **来源**：行业经验区间（最终以模流分析/试模确认）
- **意见映射**：接近上限 → B（短射风险，建议模流）；超上限 → A（大概率充填缺陷）

## R-BT-04 最大壁厚限制
- **适用**：任何厚截面区域（电池仓壁、把手、嵌件区）
- **规则**：热塑性件一般 ≤ 4.0mm；超过必须掏胶减料（筋框/蜂窝/凹坑），保持截面接近名义壁厚
- **来源**：材料商设计指南通用
- **意见映射**：>4mm 无减胶 → B；>6mm 无减胶 → A（中心缩孔几乎必然，冷却周期倍增）

## R-BT-05 壁厚公差能力
- **适用**：图纸上对壁厚或由壁厚控制的尺寸提出公差
- **规则**：注塑壁厚直接尺寸的能力约 ±0.05 ~ ±0.10mm；未注公差按 GB/T 14486（塑料模塑件尺寸公差）相应等级执行
- **来源**：GB/T 14486 + 工艺能力经验区间
- **意见映射**：要求公差 < ±0.03mm → B（超出常规工艺能力，需特殊措施：模流补偿、DOE、选材）

## R-BT-06 外观面（A 面）壁厚敏感区
- **适用**：有外观定义的零件
- **规则**：A 面区域壁厚均匀性优先级最高；A 面背面禁止布置任何造成料聚的特征（厚筋、粗柱、交汇区），判定阈值见 R-SK-01（A 面侧 1.15×t）
- **来源**：行业通用做法
- **意见映射**：A 面背面料聚特征 → B 起步；已预见可见缩痕仍不处理 → A

## R-BT-07 壁厚与收缩的关系
- **适用**：尺寸精度要求较高的零件
- **规则**：收缩率随壁厚增大而增大（半结晶材料 PP/PA/POM 尤其明显），厚区尺寸向偏小方向偏差、且厚薄交界处尺寸不稳定
- **来源**：材料商设计指南通用规律
- **意见映射**：关键尺寸位于厚薄交界处 → C（建议移位或局部均匀化）

## R-BT-08 平面刚度用筋不用厚
- **适用**：大面积平面/壳体刚度设计
- **规则**：刚度不足时加筋、拱曲、曲面，而非整体加厚——加厚带来缩水、周期、重量三重代价
- **来源**：行业通用做法
- **意见映射**：以加厚替代布筋 → C（联动 R-SK-03 大平板翘曲）

## R-BT-09 金属嵌件包覆壁厚
- **适用**：热压/超声金属螺母嵌件、金属嵌件
- **规则**：嵌件周围塑料壁厚 ≥ (0.3–0.5)× 嵌件外径（脆性材料取大值；**经验区间**，需结合材料数据核对），防包覆开裂
- **来源**：行业经验区间 + 嵌件厂商指南
- **意见映射**：< 0.3×D → B（开裂风险）；联动 R-SK-11

## R-BT-10 透明件壁厚均匀
- **适用**：PC/PMMA 等透明外观件
- **规则**：壁厚差控制在 ±20% 内且渐变过渡；禁止料聚特征（厚筋柱会在透明件内形成可见缩松与应力条纹）
- **来源**：透明材料商设计指南通用
- **意见映射**：透明件存在料聚/突变过渡 → B（光学缺陷可见）

## R-BT-11 大件多点进浇与壁厚
- **适用**：大尺寸零件（流程比接近上限）
- **规则**：大件采用多点浇口/热流道时，浇口间流动平衡需与壁厚配合评估；结构评审阶段标注浇口敏感区（A 面禁区）
- **来源**：行业通用做法（联动 R-SK-06）
- **意见映射**：大件单点进浇且 L/t 接近上限 → C（提示与模具沟通进浇方案）

## R-BT-12 壁厚标注齐套
- **适用**：所有图纸/设计说明
- **规则**：图纸应标注名义壁厚、公差与基准面；设计说明应写明材料牌号与名义壁厚
- **来源**：制图规范通用
- **意见映射**：缺失不发意见，列入"待补资料清单"
