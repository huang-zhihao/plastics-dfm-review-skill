## 快速审查路径

1. **拿到设计先算三个数**：名义壁厚 t（R-BT-01）；筋厚/t、柱壁/t（R-RB-01、R-BS-04）；最大局部截面/t（R-SK-01）
2. **逐面扫立面斜度**（R-DM-08 是新手硬伤高发项）
3. **A 面背面的所有特征过一遍料聚判定**（R-SK-01）
4. 有卡扣 → 全读 sn.md；有螺丝柱 → 全读 bs.md

## 意见分级约定（与 SKILL.md 一致）

| 等级 | 含义 |
|---|---|
| A 硬伤 | 必须修改：无法开模/功能失效/严重外观缺陷 |
| B 高风险 | 强烈建议修改：大概率缩水/变形/装配困难 |
| C 优化 | 建议采纳：降本/模具简化/量产稳定 |
| D 存疑 | 人工确认：规则库无依据或需模流/实测 |

## 来源标注约定（A/B 两类）

- **A 类**（占比 ≥60%）：国标/行标（GB/T 14486 等，标标准号）、材料商 datasheet 与设计指南（Bayer/Covestro、BASF、SABIC，标指南名）、模具手册（标手册名与页码）。意见引用时标注具体标准号/手册名
- **B 类**：行业通用经验值（如"筋厚取壁厚 50–60%"），意见中注明"经验值，建议结合实际验证"
- **禁止无标注的裸数值**；B 类不得伪装成 A 类；引用时保持原标注
