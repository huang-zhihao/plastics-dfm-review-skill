# R-SN 卡扣类规则（10 条）

卡扣是"算出来的"特征，不是"画出来的"。审查顺序：**算厚度比 → 查臂长 → 查进/导角 → 估应变 → 查根部细节**。
联动：R-HL-06（根部圆角）、R-SK-09（应力发白）、R-RB-07（根部料聚）。

## R-SN-01 卡扣臂厚度
- **适用**：悬臂式卡扣
- **规则**：臂根部厚度 ≤ 0.6×t（常用 0.5–0.6×t）；等厚直臂应力集中在根部，推荐渐缩臂（端部厚度 ≈ 0.6×根部厚），应力分布均匀、装配力更柔
- **来源**：材料商卡扣设计指南（BASF/Bayer 卡扣手册）通用
- **意见映射**：0.7–0.8×t → B（装配力过大 + 根部缩水）；> 0.8×t → A（装配即断风险）

## R-SN-02 悬臂长度
- **适用**：悬臂式卡扣
- **规则**：臂长 L ≥ 5–6× 臂厚；短臂刚性过大 → 装配力陡增、根部断裂
- **来源**：材料商卡扣设计指南通用
- **意见映射**：L < 4× 臂厚 → B；L < 3× 臂厚 → A（几乎不可装配）

## R-SN-03 进入角与导出角
- **适用**：卡钩头部斜面
- **规则**：进入角（装配方向）25°–35°；导出角（拆卸方向）≤ 45° 为可拆式；> 60° 接近不可拆（永久式），须与用途匹配并在图面明确
- **来源**：材料商卡扣设计指南通用
- **意见映射**：进入角 > 40° → B（难装/装伤）；要求可拆但导出角 > 60° → B

## R-SN-04 卡入量与许用应变
- **适用**：悬臂式卡扣变形核算
- **规则**：卡入量常用 0.5–1.5mm；装配应变 ≤ 材料许用应变（短时，**经验区间**）：ABS / PC/ABS ≈ 1.5–2%，PC ≈ 1.5%，PA ≈ 2%，PP ≈ 3–4%；应变 = 卡入量相关的梁端挠曲，按材料商卡扣公式核算
- **来源**：材料商卡扣设计指南（经验区间，牌号敏感）
- **意见映射**：应变超许用 → A（装配断裂）；达到许用的 80% 以上 → B；未核算 → C 要求补计算

## R-SN-05 卡扣根部圆角
- **适用**：所有卡扣
- **规则**：根部圆角 R ≥ 0.5–1.0mm（根部是最高应力点，禁止尖角——联动 R-HL-06）
- **来源**：材料商卡扣设计指南通用
- **意见映射**：根部尖角或 R < 0.3 → A（疲劳/装配断裂源头）

## R-SN-06 环形卡扣
- **适用**：圆周环形卡扣（瓶盖式、管套式）
- **规则**：整圈环形扣必须开槽分瓣（≥ 4 槽）或做轴向剖切，提供变形空间；过盈量 0.2–0.6mm（**经验区间**，按直径与材料）
- **来源**：行业经验区间
- **意见映射**：整圈无分瓣 → A（无法装配/胀裂）；过盈超范围 → B

## R-SN-07 数量与布置
- **适用**：卡扣组设计
- **规则**：≥ 2 个且对角/对称布置；≥ 3 个时防过定位——保留 1 个弹性补偿扣；扣合可靠性按装配力/拆卸力核算（悬臂梁：挠度 δ = FL³/3EI，装配力 = 变形力/摩擦系数，导出角影响摩擦分量）
- **来源**：行业通用做法 + 材料商公式
- **意见映射**：单扣悬臂定位（无第二约束）→ B；三点硬定位无补偿 → C

## R-SN-08 拆解预留
- **适用**：售后需拆修的卡扣连接
- **规则**：卡扣对应位置预留撬开槽/撬开孔，图面标注拆解方向与工装入口；不可拆结构（超声焊）另论
- **来源**：行业通用做法（可维护性）
- **意见映射**：无拆解预留 → C（售后维修性）

## R-SN-09 根部料聚
- **适用**：卡扣与主壁的连接
- **规则**：扣根部与主壁交汇处料聚 → 背面掏胶避让（联动 R-RB-07、R-SK-01）；A 面背面禁止裸料聚
- **来源**：行业通用做法
- **意见映射**：根部料聚未处理 → B

## R-SN-10 蠕变与温度影响
- **适用**：长期保持扣合状态的卡扣、宽温域产品
- **规则**：卡扣长期受力 → 应力松弛、保持力随时间衰减（高温加速）；低温下材料变脆、装配应变许用值下降；材料韧性排序经验：PA+GF / PC/ABS 优于纯 PP（**经验区间**）
- **来源**：材料商长期性能数据 + 行业经验
- **意见映射**：PP 卡扣 + 高温工况长期保持 → C；低温装配且无降应变 → C/B
