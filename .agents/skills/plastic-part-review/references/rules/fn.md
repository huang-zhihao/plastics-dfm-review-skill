# R-FN 表面处理类规则（8 条）

外观件（A 面）的表面处理方式反过来约束结构：蚀纹要求更大斜度、电镀禁止尖角、喷涂要求壁厚均匀。**先确认表面处理工艺，再按本类规则校核**。
联动：R-DM-03（纹理面斜度）、R-HL-06（尖角禁令）、R-BT-06（A 面壁厚）。

## R-FN-01 蚀纹/晒纹面斜度
- **适用**：有纹理（咬花/晒纹）要求的面
- **规则**：纹理越深斜度越大——每加深 0.025mm 纹深斜度约加 1°；常见晒纹面 ≥1.5°–3°；图纸须注明纹号/纹深
- **来源**：纹理供应商（Mold-Tech 类）通用推荐（A 类）
- **意见映射**：纹面斜度不足 → A（拖花外观报废）；纹号未注明无法校核 → C

## R-FN-02 喷涂件壁厚均匀
- **适用**：喷涂（喷漆/喷粉）外观件
- **规则**：喷涂对壁厚突变敏感——厚薄台阶处漆膜厚度不均、遮盖不均；大面壁厚差控制在 ±25% 内且渐变（联动 R-BT-02）；深槽/死角处喷不到（屏蔽效应），结构上避免过深内角槽
- **来源**：表面处理工艺通用要求（B 类经验值）
- **意见映射**：深槽/死角易积漆或漏喷 → C；喷涂件壁厚突变大 → C/B

## R-FN-03 电镀件避免尖角
- **适用**：电镀（ABS 电镀为主）外观件
- **规则**：尖角/锐边电流密度集中 → 镀层过厚起皮、发脆；内角尖角镀层薄、露底——电镀件外角圆角 R ≥0.3–0.5，内角 R ≥0.5（联动 R-HL-06 收紧）
- **来源**：电镀行业通用要求（B 类经验值）
- **意见映射**：电镀件尖角未圆角 → B（镀层缺陷）

## R-FN-04 电镀件材料选择
- **适用**：电镀工艺的零件
- **规则**：电镀首选 ABS 或 PC/ABS（专用电镀级）；PP/PE/POM/PC 裸材直接电镀附着力差——POM 基本不可电镀
- **来源**：材料商电镀指南（A 类）
- **意见映射**：电镀件用非电镀级材料 → A（附着力失效）

## R-FN-05 喷涂溶剂相容性
- **适用**：喷涂件材料选择
- **规则**：油漆溶剂对部分材料有攻击性——PS/PMMA 不耐强溶剂（开裂/雾化）；PC 需选专用漆；结构评审时确认材料-漆种相容性并做试喷
- **来源**：材料商与涂料商相容性数据（A 类）
- **意见映射**：不相容组合 → A（应力开裂/外观失效）；未确认 → C

## R-FN-06 免喷涂 vs 喷涂的设计差异
- **适用**：外观件工艺路线选择
- **规则**：免喷涂（模具直接成型出效果）对结构要求更高——缩痕/熔接线/浇口痕全部裸奔可见，A 面背面料聚阈值收紧至 1.15×t（联动 R-SK-01），浇口必须进非外观区；喷涂可遮蔽部分缺陷但对深槽/异色分模线敏感
- **来源**：行业通用做法（B 类经验值）
- **意见映射**：免喷涂件按喷涂件标准设计（料聚/浇口）→ B

## R-FN-07 高光 vs 磨砂/哑光设计
- **适用**：A 面表面质感定义
- **规则**：高光（镜面）面放大一切缺陷（缩痕/熔接线/拖花）——斜度 ≥2°（R-DM-09）、A 面背面禁止料聚、避免熔接线经过；磨砂/哑光对缺陷容忍度高、成本低——外观要求不高时优先哑光
- **来源**：行业通用做法（B 类经验值）
- **意见映射**：高光面按哑光标准设计 → B

## R-FN-08 丝印/烫印/镭雕面要求
- **适用**：有丝印、烫印、镭雕区域的面
- **规则**：丝印/烫印需要平整区（无纹理或指定区域）、区域边界远离结构圆角与台阶（印料刮刀/烫头贴合）；镭雕面避免高光泽底色干扰（对比度）；图面标注印字区范围与表面状态
- **来源**：表面处理工艺通用要求（B 类经验值）
- **意见映射**：印字区跨圆角/台阶 → C；印字区表面状态未标注 → C
