# R-DM 脱模斜度类规则（10 条）

脱模斜度是"没有就无法量产"的硬性要求，也是新手设计最常见硬伤。审查时先找出所有平行于开模方向的立面（侧壁、内腔、筋、柱、卡扣），逐面检查。
联动：R-RB-05（筋斜度）、R-BS-06（孔芯斜度）、R-BT-02（斜度与壁厚）。

## R-DM-01 最小斜度基线
- **适用**：所有平行开模方向的表面
- **规则**：光滑表面——型腔侧（零件外表面）≥ 0.5°，型芯侧（零件内表面）≥ 1°；常规设计取 1°–2° 更安全（兼顾顶出阻力和表面擦伤）
- **来源**：材料商设计指南 + 塑料模具设计手册通用做法（A 类，见《塑料模设计手册》）
- **意见映射**：< 0.5° 或无斜度立面 → A（拖花、顶出变形）；0.5°–1° 未说明表面状态 → B（临界，要求确认抛光/纹面）

## R-DM-02 内外表面的斜度差
- **适用**：筒形/箱形零件内外壁
- **规则**：内表面（包紧型芯）斜度必须 ≥ 外表面（脱离型腔）；内外壁同向倾斜时，壁厚以小端为基准核算
- **来源**：塑料模具设计手册通用做法（A 类，见《塑料模设计手册》）（收缩包紧型芯的物理事实）
- **意见映射**：内表面斜度小于外表面 → B（顶出拉白/拖伤）

## R-DM-03 纹理面（晒纹/咬花）加斜度
- **适用**：表面有纹理要求的面
- **规则**：斜度随纹理深度增加：每加深 0.025mm（0.001in）斜度加 1°；常见晒纹面 ≥ 1.5°–3°；图纸须注明纹号/纹深以便校核
- **来源**：纹理供应商（Mold-Tech 类）通用推荐
- **意见映射**：纹面斜度不足 → A（拖花即外观报废，必须改）

## R-DM-04 深腔件放大斜度
- **适用**：深腔/高盒体（深径比 H/D > 2）
- **规则**：斜度放大到 2°–5°；过深（H/D > 5）评估分体/拼装方案（**经验区间**）
- **来源**：行业经验区间
- **意见映射**：深腔按 1° 以下设计 → B（顶出拉伤、脱模痕）

## R-DM-05 加强筋的斜度
- **适用**：所有筋
- **规则**：筋两侧面各 ≥ 0.5°（常用 0.5°–1°）；筋以大端（根部）为厚度基准时，核算小端（顶部）厚度是否低于下限（联动 R-RB-04）
- **来源**：材料商设计指南通用
- **意见映射**：筋面无斜度 → A；斜度导致顶厚过薄 → B

## R-DM-06 螺丝柱底孔型芯斜度
- **适用**：自攻螺丝底孔、细长孔
- **规则**：底孔型芯销斜度 0.25°–0.5°（不可大——过大导致有效旋合牙数不足），柱外表面同普通立面 ≥ 0.5°
- **来源**：塑料模具设计手册通用做法（A 类，见《塑料模设计手册》）
- **意见映射**：孔芯斜度 > 1° → B（旋合长度损失、扭矩不足）

## R-DM-07 斜度与壁厚基准端
- **适用**：高立面、深腔侧壁
- **规则**：斜度累积使大小端壁厚不同，图纸应注明以哪一端为名义壁厚基准（常用小端 = 名义壁厚）
- **来源**：制图/模具通用约定
- **意见映射**：未注明基准端 → C（标注问题，避免争议）

## R-DM-08 立面必检（新手硬伤清单）
- **适用**：全部图面
- **规则**：所有平行开模方向的立面（侧壁、内腔、筋、柱、卡扣臂、窗口侧边）必须有斜度；逐面核对，不能只看主视图
- **来源**：行业通用（评审经验）
- **意见映射**：发现无斜度立面 → A（直接判硬伤）

## R-DM-09 高光面/透明件斜度
- **适用**：高抛光 A 面（钢琴面）、透明件外观面
- **规则**：高光面斜度 ≥ 2°（高抛光模面摩擦大、易拖白），透明件配合面 ≥ 1.5°–2°（**经验区间**）
- **来源**：行业经验区间
- **意见映射**：高光 A 面 < 1.5° → B

## R-DM-10 斜度标注齐套
- **适用**：所有图纸
- **规则**：图纸应注明斜度数值 + 方向（向内/向外）+ 基准端；未注斜度按企业未注标准（无则默认 1°）执行并要求图面固化
- **来源**：制图规范通用
- **意见映射**：缺失不发意见，列入"待补资料清单"
