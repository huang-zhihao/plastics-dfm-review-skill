# 结构设计评审·输入模板

提交评审前请按本模板准备资料。**关键项缺失时，评审会先追问澄清再出意见单，不会硬评**——判级依赖这些参数，硬评会翻车（如 PP 与 PC 的壁厚/应变判定可能完全相反）。

## 一、基本信息

| 项 | 内容 | 说明 |
|---|---|---|
| 零件名 / 图号 | | |
| **材料牌号** ★ | | 如 PC/ABS、PP+GF30；决定壁厚/筋厚比/应变许用（R-MA 速查） |
| **名义壁厚 t** ★ | | mm；一切特征尺寸的基准 |
| 外形尺寸 | 长 × 宽 × 高 | mm |
| 生产批量 / 模具要求 | | 模穴数、模具寿命（影响结构取舍） |

## 二、视图要求（建议至少提供）

| 视图 | 用途 | 必须标注 |
|---|---|---|
| 主视图 | 外形、壁厚分布 | 名义壁厚、分型线 |
| 关键剖面图 | 壁厚 / 筋 / 柱截面 | 筋厚、柱壁厚、圆角半径 |
| 细节放大图 | 卡扣、螺丝柱、深孔 | 卡扣尺寸、底孔、斜度 |
| 3D 截图（如有） | 补充视角 | 外观面、开模方向 |
| 2D 图纸（PDF/图片） | 尺寸与公差 | 关键尺寸公差、基准 |

## 三、标注要求

| 项 | 内容 |
|---|---|
| **外观面定义** ★ | A/B/C 面分区（A 面背面料聚阈值收紧至 1.15×t） |
| **开模方向** ★ | 脱模方向——所有立面斜度判定的基准 |
| 表面处理 | 蚀纹号 / 喷涂 / 电镀 / 免喷涂（影响斜度、圆角、材料判定，见 R-FN） |
| 装配关系 | 装配对象、方式（螺丝/卡扣/超声焊/热熔）、配合间隙 |
| 关键尺寸公差 | 配合面、孔径、位置度（GB/T 14486 等级） |

## 四、特征描述（文字或图面均可）

- **加强筋**：位置、筋厚、筋高、间距、根部圆角
- **螺丝柱**：规格（M2/M2.6…）、柱外径、底孔、柱高
- **卡扣**：臂长、臂厚、卡入量、进入/导出角
- **孔**：孔径、孔深（盲/通）、孔间距/边距

## 五、缺失项对评审的影响

| 缺失项 | 影响 |
|---|---|
| 材料牌号 | 壁厚/筋厚比/应变判定只能给通用区间（半盲评），复评才能转精判 |
| 名义壁厚 | 所有倍数类规则（筋/柱/卡扣）无法判定 |
| 外观面 / 开模方向 | 缩水、斜度、浇口判定不可靠 |
| 视图不全 | 只评审已提供的部分，其余标注"待补" |
