# case-01 标准答案（预埋问题清单）

评分口径：
- **命中** = 意见单点中该位置，且引用了对应类别规则（判级允许 A/B 差一级，记录为质量偏差）
- **误报** = 对下方"合规陷阱项"中的特征发出 A/B 级意见
- 合法的 C/D 级补充意见（如浇口存疑）不算误报
