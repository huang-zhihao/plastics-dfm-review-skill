# 塑料件结构设计评审 skill — 规则库 v2.0 发布说明

**规则总数**：125 条（10 大类）

## 一、版本概述

v2.0 是规则库首次主版本升级。自 v1.0 起，对 9 个规则文件（dm/as/bs/fn/hl/rb/sk/sn/materials）逐条核对原始标准与权威资料，累计修订 76 条规则、新增 22 条规则。核心成果：

1. **修正 3 处严重错误**：R-MA-05 PA66-GF30 收缩率各向异性（相差最高 5×）、R-SN-07 装配力公式方向相反、R-HL-02 盲孔深径比直径分界值
2. **新增 22 条规则**：覆盖 PA66-GF30 各向异性、PP 活动铰链、IMD/IML、筋交叉减胶、变形症状反查表、玻纤增强卡扣降级等
3. **升级 12 条规则为 A 类**：补全 BASF/Covestro/Envalior 等材料商指南明文背书
4. **更正 1 处来源标注错误**：《塑料模设计手册》第 3 版实际存在（ISBN 7-111-04083-X）
5. **同步 2 个关联文档**：RELEASE_NOTES.md、templates/design-input-template.md

### 5.3 三大严重错误修正

| 规则 | 原错误 | 修正值 | 影响 |
|---|---|---|---|
| **R-MA-05** | GF30 收缩率 1.0–1.6%（仅垂直向） | 流动向 0.2–0.7% / 垂直向 0.7–1.5% | 模具尺寸偏差最高 5× |

| **R-HL-02** | 直径分界 1.5mm（与所有材料商冲突） | 5mm（主流共识） | 盲孔深度判定错误 |

## 七、关键澄清与勘误

### 7.1 标准范围澄清

| 标准 | 实际范围 | 常见误用 |
|---|---|---|
| ISO 20457:2018/2026 | 仅规定尺寸公差与验收条件 | ❌ 误以为规定设计数值（壁厚/圆角等） |
| ISO 294-4:2018 | 仅是测试方法标准 | ❌ 误以为提供设计数据源（明文声明不作为） |
| SPI 101-105 | 仅定义模具寿命与表面等级 | ❌ 误以为规定脱模斜度 |
| VDI 3400 | 仅定义 EDM 纹理等级与 Ra | ❌ 误以为规定斜度 |
| ASTM D1693 | **仅适用 PE** | ❌ 误用为通用塑料 ESC 测试 |
| ASTM B604 / ISO 4525 / GB/T 12600 | 电镀层规范，**无塑件结构圆角章节** | ❌ 误以为规定圆角数值 |

### 7.2 幽灵引用勘误

| 原引用 | 实际情况 | 处理 |
|---|---|---|
| ISO 14605 | 实际为《精细陶瓷光催化测试光源》，与卡扣无关 | ❌ 删除 |
| ISO 16269 | 实际为《Statistical interpretation of data》 | ❌ 改为 ISO 175/22088/4599 |
| 《塑料模设计手册》"不可查证" | 实际存在（ISBN 7-111-04083-X） | ✅ v1.8 恢复 A 类 |

### 7.3 关键术语澄清

| 术语 | 澄清 |
|---|---|
| Faraday cage 效应 | **仅适用于静电粉末涂装**，不适用于液体喷涂 |
| 假筋（dummy rib） | 中文行业术语，无对应英文权威术语 |
