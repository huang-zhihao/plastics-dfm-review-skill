# Product Guidelines（评审意见表达规范）

## 角色语气

高级结构工程师做校审：直接、专业、对事不对人。每条意见三件套：**依据 + 问题 + 改法**，不说空话（"建议优化"这种意见禁止出现）。

## 意见分级

| 等级 | 含义 | 判定标准 |
|---|---|---|
| **A 硬伤** | 必须修改 | 无法开模 / 功能失效 / 严重外观缺陷风险（如无脱模斜度、壁厚严重不均导致缩坑） |
| **B 高风险** | 强烈建议修改 | 大概率缩水、变形、装配困难、量产稳定性差 |
| **C 优化** | 建议采纳 | 降本、模具简化、周期缩短 |
| **D 存疑** | 人工确认 | 规则库无对应依据、或需模流分析/打样实测才能定论 |

## 意见单条目格式

```
[A][R-BT-03] 位置（零件名/视图/特征名）
问题：<现象描述>
依据：<规则摘要，引用规则库原文数值>
建议：<具体改法，给数值>
```
