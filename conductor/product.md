# 塑件结构评审高工（Plastic Part Review Skill）

> 扮演高级产品结构工程师（塑料件方向），对其他工程师提交的塑料件结构设计做 DFM 与设计规范评审，输出带规则依据的 A/B/C/D 分级评审意见单。

## Problem

- 结构设计评审依赖少数资深高工，产能瓶颈、评审标准因人而异
- 初级工程师反复犯同类错误（壁厚不均、筋厚过大导致缩水、无脱模斜度、螺丝柱设计错误等），返工成本高
- 评审意见缺少结构化存档，难以追溯、复盘和沉淀为团队知识

## Solution

做成 ZCode Skill：角色与流程（SKILL.md）+ 本地规则知识库（references/）+ 意见单模板。核心纪律：**评审意见必须引用本地规则库编号，规则数值必须来自标注来源，禁止模型凭记忆给数值**——这是防幻觉、保证意见可信的关键设计。

## Target Users

| Persona | Needs | Pain Points |
|---|---|---|
| 校审高工 / 设计主管 | 减轻初审负担，意见标准化、可追溯 | 时间不够，意见格式因人而异 |
| 初中级结构工程师 | 提交前自检，边审边学设计规则 | 不知道错在哪，返工多 |
| 缺高工的小团队 / 方案商 | 获得接近高工水平的初审能力 | 请不起专职评审人员 |

## Core Features

| Feature | Status | Description |
|---|---|---|
| F1 评审流程引擎 | planned | 六步流程：资料接收 → 齐套检查 → 分类逐项审查 → 风险分级 → 意见单输出 → 复审说明 |
| F2 注塑件 DFM 规则库 | planned | 七大类核心规则：壁厚、脱模斜度、加强筋、螺丝柱、卡扣、孔与圆角、缩水/变形风险；每条带编号与来源 |
| F3 材料物性速查库 | planned | 常用材料（ABS/PC/PP/PA/POM 等）收缩率、推荐壁厚、耐温、阻燃等级 |
| F4 分级意见单输出 | planned | A/B/C/D 分级 + 规则编号 + 位置 + 依据 + 建议改法，Markdown 意见单 |
| F5 评审报告 docx | planned | 用 document-skills 生成可打印的正式意见单文档 |
| F6 图纸/截图视觉审查 | planned | 借助视觉助手读 2D 图纸与 3D 模型截图 |
| F7 复审销项 | planned | 对修改后版本复核，逐项销项记录 |

## Roadmap

- **Phase 1 (MVP)**：评审流程 + 七大类核心规则库 + 意见单输出；能对"2D 图纸 + 设计说明"文本输入做完整评审 → track: `skill-mvp_20260823`
- **Phase 2 (知识深化)**：材料库、注塑件公差审查（GB/T 14486）、装配与螺丝选用、卡扣力学估算、模具结构影响（滑块/斜顶/顶针/分型面）
- **Phase 3 (质量打磨)**：真实脱敏案例回归测试、意见命中/误报调优、docx 正式报告
- **Phase 4 (扩展)**：图纸/截图视觉审查、STEP 模型脚本测量（CadQuery）、复审销项流程、钣金/压铸件扩展

## 已确认的关键假设

- 领域为**产品结构设计中的塑料件**（注塑成型为主），不是建筑结构
- MVP 输入形态：2D 图纸文本/PDF、设计说明、BOM、3D 截图；3D STEP 解析放 Phase 4
- 交付形态：**ZCode Skill 为主体**（角色定义在 SKILL.md 内），暂不做独立 subagent；后续视需要用插件封装分享
