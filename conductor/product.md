# 塑件结构评审高工（Plastic Part Review Skill）

> 扮演高级产品结构工程师（塑料件方向），对其他工程师提交的塑料件结构设计做 DFM 与设计规范评审，输出带规则依据的 A/B/C/D 分级评审意见单。

## Problem

- 结构设计评审依赖少数资深高工，产能瓶颈、评审标准因人而异
- 初级工程师反复犯同类错误（壁厚不均、筋厚过大导致缩水、无脱模斜度、螺丝柱设计错误等），返工成本高
- 评审意见缺少结构化存档，难以追溯、复盘和沉淀为团队知识

## Solution

做成 ZCode Skill：角色与流程（SKILL.md）+ 本地规则知识库（references/）+ 意见单模板。核心纪律：**评审意见必须引用本地规则库编号，规则数值必须来自标注来源，禁止模型凭记忆给数值**——这是防幻觉、保证意见可信的关键设计。

## Target Users

| Persona | Needs | Pain Points |
|---|---|---|
| 校审高工 / 设计主管 | 减轻初审负担，意见标准化、可追溯 | 时间不够，意见格式因人而异 |
| 初中级结构工程师 | 提交前自检，边审边学设计规则 | 不知道错在哪，返工多 |
| 缺高工的小团队 / 方案商 | 获得接近高工水平的初审能力 | 请不起专职评审人员 |

| Feature | Status | Description |

## Roadmap

- **Phase 1 (MVP)** ✅ 完成（2026-08-23）：评审流程 + 九大规则类别 96 条 + Top5 材料速查 + 复审销项机制 + 来源 A/B 分类；case-01 试评 7/7 命中、零误报 → track: `skill-mvp_20260823`。二次修订（回应工程师信任与输入标准化反馈）：设计亮点机制、引导式输入模板、关键信息缺失追问优先
- **Phase 2 (知识深化)**：完整材料物性库、公差审查深化、装配深化与卡扣力学计算、模具结构影响
- **Phase 3 (质量打磨)**：真实脱敏案例回归测试 + **真实用户验证**（3 位目标用户各评审 1 个真实设计，收集意见准确性/格式/采纳与驳回率）、意见命中/误报调优、docx 正式报告
- **Phase 4 (扩展)**：图纸/截图视觉审查、STEP 模型脚本测量（CadQuery）、钣金/压铸件扩展

## 已确认的关键假设

- 领域为**产品结构设计中的塑料件**（注塑成型为主），不是建筑结构
- MVP 输入形态：2D 图纸文本/PDF、设计说明、BOM、3D 截图；3D STEP 解析放 Phase 4
- 交付形态：**ZCode Skill 为主体**（角色定义在 SKILL.md 内），暂不做独立 subagent；后续视需要用插件封装分享
- **来源策略**：规则来源分 A 类（标准/datasheet/材料商指南/手册，标标准号或手册名）与 B 类（行业经验值，标"经验值"）；A 类占比 ≥60%，禁止无标注的裸数值——保证"评审意见可追溯、数值可信"
- **输入策略（工程师信任关键）**：各公司图纸规范差异大，不假设能看懂一切图面——引导式输入（`templates/design-input-template.md` 明确视图与标注要求）；关键信息（材料/名义壁厚/开模方向/外观面）缺失时主动追问、暂缓评审，不硬评
- **信任策略**：输出必须引用具体设计准则/数据来源，不做无依据判断；意见单含"设计亮点"（合规项确认，≥2 条，引用规则编号），肯定做对的设计，避免"只挑毛病"的第一印象
